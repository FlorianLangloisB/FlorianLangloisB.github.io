# ============================================================================
# Données des personnages — édite ce fichier pour changer le contenu de la page.
#
# Une FICHE = un bloc de lignes ; une LIGNE VIDE sépare deux personnages.
# À l'intérieur d'une fiche, répartis le nom et les tags comme tu veux : un tag
# par ligne (plus lisible pour une fiche chargée), ou tout sur une seule ligne
# (pratique pour un personnage secondaire). Les deux styles peuvent se mélanger
# dans le même fichier.
#
#   Nom du personnage
#   [sagas: Saga1, Saga2]
#   [oeuvres: Film1, Film2, ...]
#   [img: chemin ou URL]
#   [info: texte]
#
#   [sagas: ...]   une ou plusieurs sagas séparées par des virgules.
#                  - la PREMIÈRE de la liste détermine la section (et sa couleur) où le
#                    personnage est rangé sur la page ;
#                  - toutes les sagas listées apparaissent en badges sur sa fiche, et
#                    permettent de le retrouver via le filtre, quelle que soit la saga
#                    choisie.
#                  L'ordre des SECTIONS sur la page suit l'ordre d'apparition des sagas
#                  dans ce fichier (en tant que saga principale) ; à l'intérieur d'une
#                  section, les personnages sont triés alphabétiquement — pas besoin de
#                  les ranger toi-même.
#   [oeuvres: ...] liste des films/séries où il apparaît, séparés par des virgules.
#                  Facultatif.
#   [img: ...]     facultatif — portrait du personnage : un chemin local (images/xxx.jpg)
#                  ou une URL complète (https://...) fonctionnent tous les deux. Si absent,
#                  la page cherche automatiquement images/<nom-slugifié>.jpg (ex. "Tony
#                  Stark" -> images/tony-stark.jpg). Si rien n'est trouvé, une pastille
#                  avec l'initiale du nom est affichée à la place.
#   [info: texte]  facultatif — note affichée dans la bulle au survol du portrait.
#                  "\n" pour revenir à la ligne dans le texte affiché ; si tu laisses le
#                  tag ouvert sur plusieurs lignes du fichier, elles sont simplement
#                  jointes par un espace.
#
# Les lignes qui commencent par # sont ignorées, y compris à l'intérieur d'une fiche.
# ============================================================================
