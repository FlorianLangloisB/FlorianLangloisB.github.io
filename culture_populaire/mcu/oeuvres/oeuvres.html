Les œuvres du MCU

Ici sont répertoriées les différentes œuvres du MCU dans l'ordre chronologique. Pour déterminer le placement, c'est le cœur de l'action de l'œuvre qui fait foi, mais si les oeuvres sont interchangeables j'ai mis l'ordre que je trouve le plus pertinent. Les scènes post-génériques peuvent se situer ailleurs dans la chronologie si elles sont distinctes de l'œuvre.
