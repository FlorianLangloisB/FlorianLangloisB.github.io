# ============================================================================
# Légende du format (les lignes commençant par # sont ignorées)
# ============================================================================
#
# Ligne de titre de section (sans ":" ni "[----]") :
#   Phase 1
#   -> affiche un grand titre de section (visible seulement en ordre chronologique).
#
# Ligne d'œuvre :
#   Année(s) de l'histoire : Titre [sortie: AAAA] [img: chemin] [info: texte]
#   - "Année(s) de l'histoire" : ce que tu veux, ex. "2010", "2018-2023", "???", "-3000"
#   - [sortie: AAAA]  année de sortie réelle du film/de la série (utilisée par le tri "Ordre de sortie")
#   - [img: chemin]    optionnel, image pour cette entrée précise (voir "Images" ci-dessous)
#   - [info: texte]    optionnel, note affichée dans la popup au survol
#
#   Une scène post-générique qui se déroule à un autre moment de l'histoire n'est pas un
#   "détail" à part : c'est juste une ligne d'œuvre de plus, avec sa propre année et,
#   si tu veux, sa propre image. Exemple : la scène post-générique de Captain Marvel se
#   passe en 2018 (contrairement au film, en 1995) -> deux lignes séparées (voir plus bas).
#
# Images :
#   Sans [img:], la page cherche automatiquement un fichier nommé d'après le titre,
#   dans un dossier "images/" à côté de oeuvres.html : les espaces et accents sont
#   retirés et remplacés par des tirets, en minuscules. Ex. pour "Iron Man 2" ->
#   images/iron-man-2.jpg
#   Avec [img: chemin-ou-url], tu choisis toi-même le fichier (utile si le nom
#   automatique ne convient pas, si plusieurs entrées doivent partager la même image,
#   ou si l'image est hébergée ailleurs). Ex. [img: images/captain-marvel-postcredit.jpg]
#   ou [img: https://exemple.com/affiche.jpg]
#
# Groupe en saga (optionnel, regroupe visuellement + colore les œuvres suivantes) :
#   [---- Nom de la saga ----]
#   ... œuvres de cette saga ...
#   [---]   (referme le groupe)
#
# Timeline alternative à l'intérieur d'une saga (optionnel, pour gérer des branches,
# ex. plusieurs continuités X-Men, Spider-Verse, What If...?) :
#   Timeline 1 [id: xmen-fox] [née-de: <id d'une œuvre>] [vers: <id d'une œuvre>] : Description
#   -> toutes les œuvres suivantes (jusqu'à la prochaine ligne "Timeline"/le prochain "[---]")
#      appartiennent à cette branche, dessinée comme un rail séparé.
#   [amont] / [aval] à la place de [née-de]/[vers] : la branche part/part vers l'inconnu
#      (trait qui s'estompe, sans point d'origine ou d'arrivée précis).
#   [id: xxx] sur une ligne d'œuvre : lui donne un identifiant, utilisable ensuite comme
#      cible de [née-de:]/[vers:] d'une timeline.
#
# ============================================================================
