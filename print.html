Le projet Barbuki

Barbuki est une collection de livres que j'ai commencé à rédiger. Ceux-ci ont pour but de redémontrer les mathématiques de licence (voire au delà), pour réaliser les objectifs suivant :

  • mettre au propre les différentes connaissances mathématiques que j'ai acquises, les ordonner et y mettre du lien, afin d'en conserver une trace sur le long terme et ne pas les oublier,
  • approfondir ce que j'ai appris, apprendre de nouvelles choses en cherchant à rédiger au mieux,
  • partager mes connaissances aux personnes qui pourraient être intéressées.

Le nom Barbuki est une référence au célèbre groupe Bourbaki, dont la démarche du Barbuki s'inspire en partie.

La consultation des fichiers pdf est gratuite, les versions physiques sont évidemment payantes puisqu’il faut payer l’impression. En voici les différents tomes que je prévois d'écrire.

Asymptote

Asymptote est un langage qui permet de faire du dessin vectoriel. Je l'apprends afin de réaliser les différents dessins que je vais mettre dans mes ouvrages de mathématiques. Actuellement j'utilise la bibliothèque TikZ en LaTeX mais elle connait ses limites dans le sens où elle est très complexe à utiliser : Asymptote se veut comme une alternative.

Je vais réunir ici les différentes commandes que j'ai apprises afin de me faire un récaptitulatif. On peut utiliser Asymptote directement en ligne via ce site internet. Pour apprendre, je consulte le document suivant.

1.3 - Chemins

1.3.1 - Principe général

Un chemin désigne le parcourt du stylo qui va tracer la figure voulue. On peut le stocker dans une variable de type path et le donner comme argument à la fonction draw pour le tracer, ou directement donner le chemin à la fonction draw.

path p = (0,0) -- (1,0); // chemin reliant deux point
draw(p);  // Pour tracer un chemin
draw((0,0) -- (1,0)); // Peut être indiqué directement dans la fonction draw

1.3.2 - Géométrie

Quelques exemples de chemin à stocker dans une variable de type path ou à donner à la fonction draw :

//  === Chemins basiques ===
(0,0) -- (1,1) -- (2,sqrt(2)) -- cycle // Revenir au point de départ
(0,0) -- (1,1) -- (2,sqrt(2)) // Ligne brisée
(0,0) .. (1,1) .. (2,sqrt(2)) // Ligne courbe

//  === Tangentes en un point du chemin ===
(0,0){up} .. (1,1) ..(2,sqrt(2)) // up,down,left,right
// On peut indiquer les coordonnées d'un vecteur tangent, avant l'arrivée au point ou après
(0,0){(1,1)} .. {right}(pi/2,1){left} .. {(1,-1)}(pi,0) 

//  === Cercles et ellipses ===
unitcircle // Cercle unité
circle((0,1), 0.5)  // Cercle avec son centre et son rayon
ellipse((1,0), 1.5, 0.5) // Ellipse avec son centre, son diamètre horizontal et son diamètre vertical

//  === Arc ===
arc((2,1), 2, 60, 80) // Centre de l'arc, rayon, degré début, degré fin
// Sens trigo si angle1 < angle2, horaire sinon 
arc((0,0), r=1, angle1=270, angle2=0)
/*Possibilité d'indiquer le centre, un point de la direction commençant et un point de la direction finissante*/
arc((0,0), (2,0), (3,4)) 
// Possibilité d'indiquer la direction : CW=horaire, CCW=trigo 
arc((0,0), (2,0), (3,4),direction=CW) 

//  === Polygones ===
box((0,0), (2,1)) // Rectangle avec deux coins opposés
polygon(5) // Polygône régulier à 5 côtés inscrit dans le cercle unité

1.3.3 - Opérations sur les chemins

// === Deux chemins peuvent s'enchaîner ===
path p = arc((2,1), 2, 60, 80);
path q = (2,1) -- p -- cycle;

//  === Transformations géométriques === 
shift(1,2)*p // Translation 
xscale(1.6)*p // Homothétie horizontale
yscale(1.4)*p // Hmothétie verticale
scale(1.8)*P // Homothétie
rotate(60)*p // Dans le sens trigonométrique, angle en degrés 
shift(-2,0) * rotate(45) * yscale(0.5) * p // Possibilité d'en enchaîner avec *

1.3.4 - Moments et intersections

Un moment d'un chemin p c'est un réel $t\in[0,1]$ représentant une proportion de la longueur de p qui a été parcourue. Par exemple si $t=0.5$ alors cela représente la moitié du parcourt de p.

path sous_chemin = subpath(p,0.25,0.75); //Sous-chemin de 25% du parcourt jusqu'à 75% du parcourt

Pour un chemin p, si jamais il intersecte la droite d'équation $x=a$ un certain nombre de fois (possiblement 1 fois), on peut récupérer la liste des "moments" où ça s'est produit avec times (un moment étant un réel $t\in[0,1]$ représentant la proportion de la longueur du chemin p parcourut).

// === Intersection entre un chemin et une droite x=a ===
path p = (0,0) -- (3,0);
real[] arr = times(p,1.5); // Array des moments où p et x=1.5 s'intersectent 
real t = arr[0]; // Premier [0] moment : donc en t=0.5 puisqu'à la moitié du parcours de p

// === Entre deux chemins ===
path q = (1,-1) -- (1,1);
real[] arr = intersect(p,q); // Array de deux éléments
real t = arr[0]; 
    /* Premier moment (le long de p) d'intersection entre p et q
    Ici 0.333... car à 1/3 du parcours de p */
real t = arr[1];
    /* Premier moment (le long de q) d'intersection entre p et q
    Ici 0.5 car à moitié du parcours de q */

// Pour plus d'un moment
real[][] arr_arr intersections(p,q); // Array à double entrées
/*
    arr_arr[0] l'array des moments pour p
        arr_arr[0][2] troisième moment pour p
    arr_arr[1] l'array des moments pour q
        arr_arr[1][5] sixième moment pour q
*/

On peut plus directement récupérer les points d'intersection plutôt que les moments

pair = intersectionpoint(p,q); //le premier point d'intersection
pair[] arr = intersectionpoints(p,q); // array de tous les points d'intersection

1.3.5 - La fonction draw

path p = (0,0) -- (1,0);
draw(p);
draw(p,red); // Couleur
draw(p,linewidth(2.0pt)) // Epaisseur du tracé
draw(p,black + linewidth(2.0pt)); // Possibilité de combiner plusieurs effets
draw(p,arrow = Arrow); // Rajouter une flèche au bout

Si un chemin est composé de plusieurs morceaux, on peut indiquer à la fin de quel morceau on souhaite placer le bout de la flèche :

path p = (0,0) -- (1,0) -- (1.5,0); //Deux morceaux
draw(p,arrow = Arrow(position = 0.5)); //Au milieu du premier morceau

// === Rajouter un marqueur aux points du tracé ===
draw(p,marker=MarkFill[0]);

1.3.6 - La fonction fill

path p = (0,0){up} .. (1,1) .. (2,sqrt(2)) -- (2,0) -- cycle;
fill(p);
fill(p,blue);

1.4 - Tailles

Il s'agit de la taille du rendu dans le pdf final.

unitsize(1cm); //Taille de l'unité 
size(3cm); /*Agrandit le plus possible de sorte que ni l'horizontal ni le vertical ne dépasse 3cm */
size(2cm,3cm); 
/*will ordinarily produce a picture that is either 2 centimeters wide (and ≤ 3 centimeters tall) or a picture that is 3 centimeters tall (and ≤ 2 centimeters wide). In either case, the height-to-width ratio is preserved */
size(4cm,0); 
/* will ordinarily be scaled so that the width is exactly 4 centimeters. The height will be the “natural” height for this scaling factor. */
size(real, real, keepAspect=false); 
/* will scale the width and height independently so that the resulting picture has exactly the specified width and height, but the height-to-width ratio is allowed to change */

Notion de marge lors du début et de la fin d'un chemin :

real epaisseur = linewidth(currentpen);
margin ArrowMargins = TrueMargin(linewidth, 0.5 linewidth);
path p = arc((0,0), (2,0), (3,4));
draw(p, arrow=Arrow(TeXHead), red, margin=ArrowMargins);

1.5 - Clip une zone

La fonction clip permet de ne conserver des dessins que ce qui se situe dans la zone clipée. Cela concerne tout ce qui est dessiné avant l'appel de la fonction. clip

path boite = box((0,0),(0,1));
clip(boite);
